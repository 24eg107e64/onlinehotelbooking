# 🏨 Online Hotel Booking System

## 📌 Project Description

Online Hotel Booking System is a web-based application that allows users to create an account, login, view available hotels, book rooms, and manage their bookings.

## 🚀 Features

- User Registration
- User Login
- View Available Hotels
- Hotel Room Selection
- Hotel Booking
- Check-in and Check-out Date Selection
- Automatic Total Price Calculation
- View My Bookings
- Cancel Booking
- Logout

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Java
- Spring Boot
- Spring Data JPA

### Database
- MySQL

- Visual Studio Code
- Maven

- GitHub
